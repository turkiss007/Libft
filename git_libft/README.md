Description
This proyect consist about the creation of an own library made with C. It has some functions that could be useful in the future to use in other 42 proyect, because as it is known, we can not use most of the libraries, we have to create them or create our own functions.
The main objective of this proyect is to know how every function that we could need to use during C programming has been made, and so, now deeply what they do.

Instructions
In GitHub:
    click on Code > Download ZIP
Ones it is downloaded:
    go to your files > Downloads > and extract the content.
    Right click on the file > Open in terminal
In the terminal you have some command you can do:
    Make or Make all - to create the library libft.a so you can used it and all the files.o needed to compile.
    Make clean - to remove every file.o
    Make fclean - to remove every file.o and libft.a
    Make re - do make fclean and then make
